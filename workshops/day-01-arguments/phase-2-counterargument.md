# Phase 2 — Building & Evaluating a Counterargument

Phase 1 took Jordan's argument apart. Phase 2 uses that breakdown to build a
counterargument — and, more importantly, to understand *why* a counterargument works.

## The key idea
A strong counterargument isn't just "I disagree." It does two jobs:
1. It targets the actual weak points found in Phase 1 (e.g., the anecdote about the
   cousin's school, the "everyone does it" appeal, the attack on teachers' motives).
2. It honestly engages the argument's *strongest* point instead of pretending it isn't
   there. (Jordan's "lunch is our own time" is genuinely reasonable — a good counter has
   to deal with it, not dodge it.)

A counterargument that ignores the strong point, or that attacks a weaker version of the
argument than what was actually said (a "straw man"), is weak no matter how confident it
sounds.

## What students produce
- A counterargument to Jordan in which each move is tied to a specific weakness or to the
  strong point.
- An evaluation of a counterargument (their own and the AI's) using `phase-2-rubric.md`.

## How to run it
1. Using their Phase 1 weakness list, students draft their own counterargument first —
   no AI — labeling which weakness each point targets.
2. They run `prompts/phase-2-counter.md` (Prompt A) to generate an AI counterargument
   that labels its own moves.
3. They compare: which counter targeted the real weaknesses? Which engaged the strong
   point honestly? Which slipped into its own fallacies?
4. They run Prompt B to evaluate the stronger of the two against the rubric, then revise
   it once.
5. Debrief: a counterargument earns its strength by what it *targets*, not by how forcefully
   it disagrees.
