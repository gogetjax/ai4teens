# Present-Back Rubric (facilitator — don't hand to students)

Score each criterion 0–2. 0 = not shown, 1 = partial, 2 = solid.

| Criterion | What you're listening for |
|-----------|---------------------------|
| Own words | The explanation sounds like the student, not a pasted AI summary. Survives being asked to "say it differently." |
| Accuracy | The plain-language version is actually correct — no key term quietly dropped or mangled. Check against the answer key. |
| Analogy + limit | Offers an analogy AND names where it breaks. Naming the limit scores higher than a slick analogy with no caveat. |
| Handles questions | Answers at least one unrehearsed question without notes. |
| Shows the process | Can describe how they decoded it — which prompts, what was missing — not just the end result. |

10 = mastered; 7–9 = solid, push harder on questions; 4–6 = likely leaned on the
AI's words, re-run Phase 3; ≤3 = restart from Phase 1 together.

Note: a confident analogy the student *knows* is partly wrong beats a
perfect-sounding one they can't question. Reward the seams.
