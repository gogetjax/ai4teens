# Prompt: Define the terms

Use this first, to clear your unknown-word list.

```
I'm going to paste a dense passage. List every word or phrase that a 14-year-old
probably wouldn't know. For each one, give a one-sentence definition in plain
language that does NOT use any other technical terms. Do not summarize or explain
the passage yet — just give me the glossary. When you're done, ask me which of
these terms is still fuzzy so we can go deeper on those.

Passage:
[PASTE THE PASSAGE]
```

Why it works: it forces small, checkable answers instead of one big summary you'd
be tempted to copy.
