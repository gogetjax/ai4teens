# Prompt: Build from the fundamentals

Use this when the passage assumes things you were never taught.

```
Here's a passage I want to understand from the ground up:

[PASTE THE PASSAGE]

Don't explain the passage yet. First, list the background ideas I need to
understand BEFORE this passage can make sense, ordered from simplest to hardest.
Give each a one-line plain explanation. Then stop and ask me which ones I already
know, so we only build on what I'm actually missing.
```

Why it works: most "hard" passages aren't hard — they just stand on a step you
skipped. This finds the missing step.
